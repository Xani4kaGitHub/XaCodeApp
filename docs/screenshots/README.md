# Screenshots

This directory is intended for screenshots of the XaCode interface, which will be displayed in the main `README.md`.

## Required Screenshots

To make the documentation complete, the repository owner should take the following screenshots and place them in this folder with the exact names:

- `main-window.png`: A screenshot of the main chat screen and interface.
- `model-team.png`: A screenshot of the Model Team setup or the team live room in action.
- `permissions.png`: A screenshot showing the project-level or global permission settings.
- `demo.gif` (optional): A short GIF showing a real scenario of the application working (without showing API keys or sensitive data).

*Note: Please ensure no API keys, tokens, personal paths, or confidential data are visible in these screenshots.*
